# syncotrope

Images to video.

Runs entirely in the browser (WebGL2 and WebCodecs): images are never uploaded. Needs a recent Chrome, Edge, Firefox or Safari.

## Prerequisites
- Install [Bun](https://bun.sh/)

## Setup
```
git clone git@github.com:nickhobbs94/syncotrope.git
cd syncotrope
bun install
```

## Build
```
bun run build
```

## Run
```
bun run start
```

## Test
```
bun test
```
